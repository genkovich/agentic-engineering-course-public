# review-target — course-project billing core (з посіяним багом)

Це той самий репозиторій, який ревʼює наш hosted code-reviewer у всіх чотирьох
скринкастах лекції 10.7. Не абстрактний снипет, а маленький реальний модуль
рахунків: `subtotal → discount → tax → total`.

## Посіяний баг (для автора демо, не для агента)

`src/invoice.js` рахує знижку через `applyDiscount`, яка **округлює до цілих
центів** (`src/discount.js`). Потім `buildInvoice` округлює суму ще раз. Подвійне
округлення губить цент на дробових входах.

Канонічний кейс:

```
buildInvoice([{ price: 19.99, qty: 3 }], { discountPercent: 10, taxPercent: 8.25 })
// баг:      total = 58.42
// правильно: total = 58.43
```

Unit-тести (`test/invoice.test.js`) зелені: жоден не зачіпає дробовий шлях, тому
баг проходить крізь suite непоміченим. Саме це має спіймати рев'юер, а рубрика
`../rubric.md` робить критерій «спіймати цей цент» вимірюваним для grader-а.

Виправлення (якщо треба показати fixed-стан): забрати проміжне округлення в
`applyDiscount` і округлювати рівно один раз наприкінці `buildInvoice`.

## Запуск тестів

```bash
cd review-target && node --test
```
