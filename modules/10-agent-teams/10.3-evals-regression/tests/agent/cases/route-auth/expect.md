# route-auth — що означає PASS

Людино-читабельний контракт (machine-checked у `check.sh`):

- `GET /private` без заголовка `Authorization` → **401 Unauthorized**.
- `GET /private` із `Authorization: Bearer secret-token` → **200 OK**.
- `GET /public` без заголовка → **200 OK** (залишився відкритим).

Чому асерт на HTTP-коди, а не на текст агента: прогін недетермінований — агент може
реалізувати middleware по-різному (раннє повернення, окрема функція, перевірка в handler).
Нам байдуже ЯК; нам важливо, що **поведінка сервісу** збіглася з наміром. Підняти сервіс і
зробити curl — найчесніший сигнал.
