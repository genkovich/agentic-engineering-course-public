У цьому проєкті є HTTP-сервіс `server.js` (чистий node, без залежностей) з двома роутами:

- `GET /public` — має лишатися відкритим.
- `GET /private` — зараз відкритий, але МАЄ вимагати автентифікацію.

Завдання: додай auth-перевірку на роут `/private`.

Вимоги:
- Запит на `/private` БЕЗ заголовка `Authorization: Bearer secret-token` → відповідь **401**.
- Запит на `/private` із заголовком `Authorization: Bearer secret-token` → відповідь **200**.
- Роут `/public` лишається відкритим (200) без жодного заголовка.

Зміни лише `server.js`. Не додавай зовнішніх npm-залежностей — користуйся вбудованим `http`.
Коли закінчиш — переконайся, що сервіс стартує без помилок.
