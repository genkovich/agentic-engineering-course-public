# tdd-three-commits — що означає PASS

- Рівно **3 коміти** (крім seed) з префіксами у порядку: `test(` → `feat(` → `refactor(`.
- `test/` **не змінювали** після фази RED (`git diff HEAD~2 HEAD -- test` порожній).
- `node --test` зелений на HEAD.

Предмет eval — **TDD-дисципліна** (порт скіла 7.7 на `node:test`): чекер перевіряє ПРОЦЕС
(порядок фаз, незмінність тестів, зелений гейт), а не зміст тестів.

> **Чесна нотатка (найфлакіший кейс).** Зробити рівно 3 атомарні коміти RGR за один
> headless-прогін `claude -p` — найскладніше. У 7.7 це робить оркестратор із 3 ізольованих
> агентів; тут один агент веде скіл `/tdd`. Якщо кейс «мигає» — це і є ілюстрація
> недетермінізму agent-run-ів: саме тому асерт на OUTCOME, а `make check` лишається
> завжди-зеленим CI-шаром. Для надійного RGR дивись повний оркестратор у 7.7.
