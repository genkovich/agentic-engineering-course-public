Проведи задачу зі `tasks/story.md` через TDD за скілом `/tdd`: RED → GREEN → REFACTOR.

Очікуваний результат — рівно 3 атомарні коміти у такому порядку:
1. `test(slug): …` — спочатку написані тести (`test/slug.test.js`), гейт червоний.
2. `feat(slug): …` — мінімальна реалізація, гейт зелений.
3. `refactor(slug): …` — чистка, гейт лишається зеленим.

Після фази RED НЕ змінюй файли в `test/`. Гейт — `node --test`.
