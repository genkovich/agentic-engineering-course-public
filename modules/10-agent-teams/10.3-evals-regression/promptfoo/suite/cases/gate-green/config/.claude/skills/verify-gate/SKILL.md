# verify-gate — реалізувати за детермінованим гейтом (node:test)

Канал #1: машина дає однозначний pass/fail, «готово» вирішує зелений гейт, не модель.
Це порт скіла 7.6 (там `tsc --noEmit && npm test`) на вбудований `node --test`.

## Гейт

```bash
node --test
```

Той самий набір ганяє Stop-hook `.claude/hooks/verify.sh` — він не дасть завершити хід,
поки гейт червоний.

## Кроки

1. Прочитай тести в `test/` — вони фіксують намір (НЕ редагуй їх).
2. Прожени гейт як baseline (`node --test`) — побач, який assert червоний.
3. Реалізуй мінімальну зміну в `src/`, що закриває червоний assert.
4. Прожени гейт знову. Червоний — читай assert, виправляй. Не йди далі, поки не зелено.
5. Доказ перед DONE: встав вивід `node --test` («pass N») у відповідь.

## Завершальне правило

> Перш ніж сказати DONE: `node --test` має бути зеленим, а вивід — вставлено у відповідь.
> НЕ редагуй і не `.skip` тести, щоб «пройшов» гейт — це обхід дисципліни.
