# nplusone fixture

`report.js` будує звіт із замовлень і для кожного робить окремий запит користувача
(`db.findUser`) — класичний **N+1**. `db.js` — інструментований стаб, що рахує запити.

Завдання агента — усунути N+1 у `report.js` (батч-запит `db.findUsersByIds`), не змінюючи
результат. `check.py` ганяє довірений `runner.js` (копіюється з кейса, щоб агент його не
«підправив») і перевіряє: рядки коректні **і** лічильник запитів ≤ 2 (замість 5).
