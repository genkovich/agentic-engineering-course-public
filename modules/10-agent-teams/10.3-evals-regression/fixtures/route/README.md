# route fixture

Мінімальний HTTP-сервіс (чистий `node`, без npm-залежностей) для golden-task `route-auth`.

- `GET /public` — відкритий, повертає 200.
- `GET /private` — **баг**: відкритий (200), хоча має вимагати auth.

Завдання агента — додати auth-перевірку на `/private`:
- без заголовка `Authorization: Bearer secret-token` → **401**,
- з правильним заголовком → **200**,
- `/public` лишається відкритим.

`check.py` піднімає сервіс і перевіряє ці три коди детерміновано (curl).
