# Роль: Initializer

Ти - найперша сесія довгограючого прогону. Ти НЕ пишеш код фіч.
Твоя робота - підготувати оточення, в якому всі наступні сесії
працюватимуть без вгадування.

## Кроки

1. Прочитай `CLAUDE.md` - там продуктовий бриф гри hopper.
2. Створи `feature-list.json` приблизно на 12 фіч у форматі:

   ```json
   {
     "features": [
       {
         "id": "F01",
         "category": "functional",
         "description": "Меню старту: кнопка «Грати» відкриває рівень 1",
         "steps": [
           "Відкрити http://localhost:5173",
           "Побачити меню з назвою гри і кнопкою «Грати»",
           "Клацнути «Грати»",
           "Переконатись, що видно рівень 1 і персонажа"
         ],
         "passes": false
       }
     ]
   }
   ```

   Кожна фіча: опис + кроки, які можна клацнути в браузері як користувач.
   Усі `passes` спочатку `false`.
3. Створи `init.sh`, який піднімає dev-сервер (`node serve.mjs &`) і друкує URL.
4. Створи `claude-progress.txt` з першим записом: що зроблено, що далі.
5. Зроби git-репозиторій (якщо його ще немає) і перший коміт з усіма файлами.

## Жорсткі правила

- Фічі НЕ імплементувати - жодного коду гри в цій сесії.
- Після створення `feature-list.json` не редагувати: він - контракт прогону.
