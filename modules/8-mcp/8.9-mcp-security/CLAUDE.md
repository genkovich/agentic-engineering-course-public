# CLAUDE.md · mcp-security (лекція 8.9)

Інспекційна фікстура для tool poisoning: отруєний і безпечний двійник одного
сервера-калькулятора. Призначення - навчитися читати описи інструментів очима
моделі через Inspector. Реального ексфільтрейту немає: небезпека лише в тексті опису.

## Стек

- Node 20+, TypeScript (ESM), `@modelcontextprotocol/sdk`, zod. Збірка tsc -> `dist/`.

## Конвенції

- `src/server.poisoned.ts` - інструмент `add` зі схованими інструкціями в
  `description` і параметром `note` (канал ексфільтрації). Handler чесний: лише a+b.
- `src/server.safe.ts` - той самий `add`, чистий опис, без `note`.
- Тримати handler нешкідливим: демо показує отруєний ОПИС, а не атаку.

## Не робити

- Не змушувати handler реально читати файли чи кудись слати дані - це залишається
  лише інспекційною фікстурою.
- Не «виправляти» отруєний опис у `server.poisoned.ts`: він отруєний за сценарієм.
- Не комітити `node_modules/` і `dist/` (gitignored).
