# CLAUDE.md · what-is-mcp (лекція 8.1)

Конфіг-кит до концептуальної лекції 8.1. Власного коду немає - сенс теки в тому,
щоб одним `make inspect` побачити готовий публічний MCP-сервер очима клієнта
(initialize + tools/list через MCP Inspector).

## Стек

- Лише `npx` + MCP Inspector (`@modelcontextprotocol/inspector`) + публічний сервер
  Context7 (`@upstash/context7-mcp`). Нічого не встановлюється і не збирається.

## Конвенції

- `make inspect` - єдиний таргет: tools/list публічного Context7 без ключа.
- `.mcp.json.example` - той самий сервер для підключення у Claude Code (урок 8.3).

  про підключення й інспекцію готового.
- Не вписувати реальні токени у `.mcp.json.example` (Context7 їх і не потребує).
