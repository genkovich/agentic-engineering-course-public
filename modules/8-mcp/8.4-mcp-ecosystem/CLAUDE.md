# CLAUDE.md · mcp-ecosystem (лекція 8.4)

Конфіг-кит до уроку про екосистему готових серверів. Власного коду немає: три
куровані сервери першого кола довіри у `.mcp.json.example`, дві шпаргалки рішень
у `DECISION.md` і один живий `make inspect` на Context7.

## Стек

- Лише `npx` + MCP Inspector. Сервери з прикладів - офіційні (Context7, GitHub MCP,
  Playwright MCP).

## Конвенції

- `DECISION.md` - джерело правди по чек-листу довіри і матриці MCP vs CLI.
- `.mcp.json.example` - лише сервери першого кола; community-приклади навмисно не
  кладемо у файл, щоб ніхто не скопіював непарсений сервер.

## Не робити

- Не додавати у `.mcp.json.example` community-сервери без проходження чек-листа.
- Не вписувати реальні токени - тільки `${GITHUB_TOKEN}`-плейсхолдер.
