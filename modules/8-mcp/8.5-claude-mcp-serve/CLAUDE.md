# CLAUDE.md · claude-mcp-serve (лекція 8.5)

Скрипт-кит навколо вбудованого `claude mcp serve`. Власного коду немає - сервер
це сам Claude Code. Тека дає Inspector-команди, щоб побачити його тулбокс, єдиний
примітив tools і виклик Read без моделі й без підтверджень.

## Стек

- `claude` (Claude Code CLI) у ролі сервера + MCP Inspector через `npx`.
- Жодних залежностей, збірки чи тестів.

## Конвенції

- `make tools` / `no-resources` / `read` - три демо-команди з лекції.
- `serve-demo.txt` - файл-мішень для `make read`; вміст довільний.

## Не робити

- Не писати тут власний сервер: сенс уроку саме в тому, що сервер вже є - це
  встановлений Claude Code.
- Не виставляти `claude mcp serve` у мережу: він виконує виклики без підтверджень.
