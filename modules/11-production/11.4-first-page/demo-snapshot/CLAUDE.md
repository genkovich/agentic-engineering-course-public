# CLAUDE.md — home-srv

Статус-панель домашнього сервера: Vite + React + Tailwind v4 + shadcn/ui.
Дизайн-система живе в одному файлі `src/index.css` (токени `:root` / `.dark`, підключення через `@theme`).

## Естетичний напрям (читається на кожній UI-задачі)

Цей блок — постійний гайданс вигляду для проєкту. Він тримає генерацію подалі від «середнього»
(заїжджені шрифти, дефолтні сітки) і проговорює ті самі чотири виміри, що й навичка `frontend-design`.

- **Типографіка.** Моноширинний шрифт для всіх чисел, лейблів, портів і станів (`--font-mono`,
  завжди `tabular-nums`). Sans (`--font-sans`) — тільки для заголовка сторінки і прози. Без Inter,
  Roboto, Arial: голос продукту — технічний монітор, не дефолтний дашборд.
- **Колір і тема.** Темна тема за замовчуванням; єдиний акцент (`--primary`, зелений) означає
  «здорове». Семантика стану окремо від акценту: `--chart-1` — працює, `--destructive` — впав,
  `--muted-foreground` — оновлюється. Кожне значення бере токен з `index.css`, ніколи голий hex.
- **Motion.** Один стриманий зрежисований момент — поява карток на завантаженні
  (`animate-card-enter`, з `prefers-reduced-motion: reduce`). Без розсипу дрібних ефектів.
- **Фони і поверхні.** Майже чорне тло (`--background`), картки на `--card` з кільцем
  `ring-foreground/10` замість важкої тіні. Щільна сітка на десктопі, одна колонка на телефоні.

## Компоненти

Тільки з `src/components/ui` (реєстр shadcn/ui). Нові компоненти додавай командою
`pnpm dlx shadcn@latest add <name>`, не винаходь примітиви-двійники. Дані заходять типізованими
властивостями (union-типи для станів), не вшиваються в розмітку.

## Перевірка

- Тип-контроль: `pnpm exec tsc -p tsconfig.app.json --noEmit`.
- Рендер: `node scripts/screenshot.mjs http://localhost:5173 <name> shots/` (валить на overflow).
