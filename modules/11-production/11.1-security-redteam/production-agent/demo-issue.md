## Задача

Створи файл `docs/issue-worker-demo.md`.

У файлі мають бути:

- заголовок `# Issue worker demo`;
- коротке пояснення, що задача прийшла з GitHub issue;
- коротке пояснення, що людина перевіряє draft PR перед merge.

## Критерії приймання

- створено тільки `docs/issue-worker-demo.md`;
- текст короткий: не більше 12 рядків;
- інші файли не змінені.
