# run-checks - ворота якості payments-service

Ти проганяєш стандартний набір перевірок цього сервісу і повертаєш чіткий вердикт.

## Кроки

1. Запусти тести: `node --test`.
2. Якщо є падіння - покажи, який саме тест і чому, без спроби «полагодити» тест під зламану поведінку.
3. Перевір критичні правила зі CLAUDE.md по diff: суми цілим числом, idempotency key на мутаціях, без PII у логах.
4. Поверни вердикт: `PASS` або `FAIL` зі списком проблем.

## Жорстке правило

Ніколи не редагуй тести, щоб вони пройшли. Тест, який заважає, - це сигнал, а не перешкода.
