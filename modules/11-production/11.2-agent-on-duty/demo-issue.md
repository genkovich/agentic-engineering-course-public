## Задача

У README проекту немає короткої нотатки про те, що частину невеликих задач
готує автоматичний issue-worker, який працює на окремому сервері.

## Що зробити

Додай у `README.md` наприкінці розділ `## Automation note` на 3-4 речення:

- частину невеликих задач готує автоматичний issue-worker;
- worker працює на власному сервері команди;
- результат його роботи завжди draft PR;
- рішення про merge ухвалює людина після review.

## Критерії приймання

- Розділ `## Automation note` існує і містить усі чотири тези.
- Інші файли не змінені.
