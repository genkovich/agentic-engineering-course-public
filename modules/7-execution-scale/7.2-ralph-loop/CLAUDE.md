# CLAUDE.md · Ralph loop abstract demo (Lecture 7.2)

Мінімальний контекст для self-contained Ralph-демо. Задача навмисне абстрактна —
урок про сам цикл, а не про конкретну бізнес-фічу.

## Стек

- Python 3.12, `pytest`. Без бізнес-залежностей (тільки стандартна бібліотека).
- Код: `app/`. Тести: `tests/test_*.py`.

## Конвенції

- **Модулі** — у `app/<name>.py`. Публічні функції експортуються напряму.
- **Atomic commit per story** — кожен закритий task у `tasks/tracker.md` = окремий
  commit з префіксом `feat:` (нова фіча) або `fix:` (виправлення).
- **Test-first** — тест існує ДО реалізації; код пишемо, щоб тест став зеленим.

## Не робити

- Не змінювати `tests/` — якщо тест падає, фіксити код, не тест.
- Не змінювати story-файли в `tasks/` — це контракти.
- Не комітити `cost.log`, `DONE`, `app/__pycache__/`, `.venv/`.
