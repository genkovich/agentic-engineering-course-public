# PROMPT.md · Ralph loop (`<STORY_ID>`)

> Шаблон. Скопіюй у `PROMPT.md` поруч із `ralph.sh` і заміни всі плейсхолдери
> `<…>` під свій стек. Тримай цей файл тонким - усе, що росте, живе в `CLAUDE.md`
> і в story-файлах, а PROMPT.md лише на них посилається.
>
> Плейсхолдери: `<STACK>` (наприклад `Python 3.12 + pytest` / `Go 1.26` /
> `Node 22 + vitest`), `<CODE_DIR>` (тека коду, наприклад `app` / `src` / `internal`),
> `<TEST_DIR>` (тека тестів, наприклад `tests`), `<STORY_ID>` (ідентифікатор історії,
> наприклад `story-1` / `S-1`), `<TEST_CMD>` (команда тестів, наприклад `pytest -q`
> / `go test ./...` / `npm test`).

## Контекст

Ти працюєш у проекті на стеку `<STACK>`. Код живе в `<CODE_DIR>/`, тести - у `<TEST_DIR>/`.

Прочитай перед роботою:
- `CLAUDE.md` у корені - конвенції проекту (стек, дисципліна, заборони).
- `tasks/tracker.md` - бэклог; обери першу історію у статусі `todo` без блокерів.
- Файл історії з `tasks/` - повний контракт задачі: опис, acceptance criteria
  (критерії приймання), checklist, критерій завершення.

Подивись на існуючі файли в `<CODE_DIR>/` і `<TEST_DIR>/` як на референс, перш ніж писати свій код.

## Завдання

Реалізувати історію `<STORY_ID>` зі статусу `todo` в трекері. Дотримуйся конвенцій `CLAUDE.md`.

Дисципліна:
- Один atomic commit (один маленький самодостатній коміт) на одну закриту історію, префікс `feat:`.
- Коли всі історії в трекері закриті - створи файл `DONE` у корені і завершуй.
- Якщо застряг (тест падає з причини, яку не можеш виправити за 3 ітерації) - додай
  рядок `BLOCKED: <причина>` у `tasks/tracker.md` і виходь.

## Критерій завершення

Бінарний - або виконано, або ні, без місця для тлумачень:
- `<TEST_CMD>` завершується з кодом 0 (зелено).
- Історія `<STORY_ID>` у `tasks/tracker.md` помічена `done`.
- Зроблено atomic commit з префіксом `feat:` для виконаної історії.
- Коли всі історії `done` - у корені існує файл `DONE`.

## Не роби

- Не міняй тести у `<TEST_DIR>/`. Якщо тест падає - виправляй код, не тест.
- Не запускай `--dangerously-skip-permissions`. Максимум - `acceptEdits` (модель сама
  застосовує правки файлів, але не виконує довільних команд без дозволу).
- Не змінюй `CLAUDE.md` і самі story-файли - це контракти.
