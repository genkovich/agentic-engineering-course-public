# Рецепт: дашборд `claude agents` - аудит фонових сесій

`claude agents` відкриває дашборд (dashboard - єдиний екран зі станом усіх
сесій) усіх твоїх агентів: фонових, запланованих, активних. Це твій
центральний пульт, щоб не загубити жодну сесію.

```bash
claude agents
```

## Шість станів

Кожна сесія в дашборді має один із шести станів:

| Стан | Що означає |
|---|---|
| Working | зараз працює, крутить хід |
| Needs input | зупинилась і чекає на твою відповідь чи дозвіл |
| Idle | жива, але простоює (нічого не робить) |
| Completed | відпрацювала і завершилась успішно |
| Failed | завершилась з помилкою |
| Stopped | зупинена (вручну або умовою) |

## Дві групи

Сесії згруповані, щоб одразу видно було, що потребує уваги:

- **Pinned** - закріплені сесії; їх супервайзер не прибирає за простій (на відміну
  від незакріплених, які підбираються приблизно через годину - див. `background.md`).
- **Ready for review** - сесії, що закінчили роботу і чекають на твій перегляд
  (типово - результат у гілці `claude/...`).

## Клавіші

| Клавіша | Дія |
|---|---|
| `Ctrl+T` | закріпити сесію (pin) - захистити від прибирання за простій |
| `Space` | швидкий перегляд (peek) сесії, не входячи в неї повністю |
| `Ctrl+X` | прибрати завершені (clear completed) - почистити список від Completed/Failed |

## Як це працює на практиці: регулярний аудит

Головне застосування дашборда в лекції 7.5 - **регулярний аудит проти забутих
сесій, що протекли**. Фонові сесії (`/background`) і рутини (`/schedule`) легко
завести й забути; кожна з них може палити токени чи писати в гілки `claude/...`
непомітно.

Раз на день відкривай `claude agents` і пройдись очима:

1. Чи є сесії в **Needs input**, що мовчки чекають на тебе тижнями.
2. Чи є **Idle**, які давно мали б завершитись, - кандидати на зупинку.
3. **Completed/Failed** - переглянь результат (`Space`), забери `Ctrl+X`.
4. Те, що має жити довго, - закріпи `Ctrl+T`, щоб супервайзер не прибрав.

Так дашборд стає твоїм запобіжником від «забув, що ця рутина досі крутиться».
Тверда стеля витрат усе одно на тобі - дашборд лише робить протікання видимим.
