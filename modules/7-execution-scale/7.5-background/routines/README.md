# Хмарна рутина через `/schedule`

Рутина (routine) - агент, що крутиться за cron-розкладом **на інфраструктурі
Anthropic**, а не на твоїй машині. Це найвищий рівень розкладу з лекції 7.5:
твоя машина може бути вимкнена, рутина все одно відпрацює.

Ключове, що відрізняє хмарну рутину від двох локальних рівнів:

- **Крутиться у хмарі.** Твоя машина не потрібна.
- **НЕ бачить локальних файлів.** Щоразу бере свіжу копію репозиторію з git.
  Усе, чого нема в git (під `.gitignore`, незакомічене, поза репозиторієм), для
  рутини **не існує**. Це головна пастка лекції - детально нижче.
- **Найменший інтервал - 1 година** (на відміну від 1 хвилини в локального `/loop`).
- **Пуш за замовчуванням тільки в гілки `claude/`.** Рутина не пушить тобі в
  `main` - вона штовхає роботу в окрему гілку `claude/...`, щоб ти переглянув і
  змерджив свідомо.

## Як завести нічну хмарну рутину

```
claude
  # /schedule create "щодня 03:00" "підбий дайджест змін у репозиторії за добу і поклади в reports/"
```

Перший аргумент - розклад (cron-вираз або зрозумілий опис), другий - промпт.
Рутина зʼявиться у списку і запускатиметься сама.

## Керування рутинами: `list | update | run`

```
claude
  # /schedule list           переглянути всі рутини (id, розклад, статус)
  # /schedule update <id> "щодня 04:00"   змінити розклад наявної рутини
  # /schedule run <id>        прогнати рутину негайно, поза розкладом (для перевірки)
```

`/schedule run <id>` - твій спосіб перевірити рутину, не чекаючи ночі: вона
виконається тут і зараз, але на тій самій свіжій копії з git.

## Worked-приклад пастки: рутина «підсумуй `drafts/`» поверне порожньо

Заведемо рутину, яка щоночі підсумовує твої чернетки:

```
claude
  # /schedule create "щодня 03:00" "підсумуй усі нотатки в drafts/ і поклади огляд у reports/digest.md"
```

У цьому демо `drafts/` містить `example-note.md` з живими думками. Локально ти
його бачиш. Але `drafts/` стоїть у `.gitignore` (відкрий `../.gitignore` - там
рядок `drafts/`). Тому:

1. Рутина прокидається о 03:00 на інфраструктурі Anthropic.
2. Вона бере **свіжу копію репозиторію з git**.
3. У цій копії теки `drafts/` **немає** - git про неї не знає.
4. Рутина чесно підсумовує порожнечу і кладе порожній (або «нема що підсумувати»)
   `digest.md`.

Це не баг рутини. Це властивість рівня: хмара працює зі станом, що є в git, і ні
з чим іншим. Якщо хочеш, щоб рутина щось побачила - спершу **закоміть** це.

Перевірити здогад можна, не чекаючи ночі:

```
claude
  # /schedule run <id-рутини>     прожене зараз; огляд drafts/ вийде порожнім
```

## Коли хмарна рутина доречна, а коли ні

| Доречна | Не доречна |
|---|---|
| робота лише над тим, що вже в git (закомічений код, доки) | усе, що залежить від незакоміченого чи `drafts/` |
| твоя машина буває вимкнена вночі / на вихідних | потрібен інтервал щільніший за 1 годину (тоді `/loop`) |
| результат не страшно отримати в гілці `claude/` на ревʼю | потрібен миттєвий локальний стан робочої директорії |

Для локального стану робочої директорії бери `/loop` (`../recipes/loop.md`) або
desktop scheduled task - вони бачать локальні файли. Хмарна рутина - ні.

## Запобіжники

- Тверда стеля витрат - на тобі. Постав алерт на сплеск витрат в Anthropic Console.
- Вбудовані запобіжники рутин і так працюють (термін життя, ліміт задач на сесію,
  jitter тощо) - повний список у `../README.md`, розділ «Покриття концептів лекції».
- Глобально вимкнути всі cron-рутини можна змінною середовища `CLAUDE_CODE_DISABLE_CRON`.
