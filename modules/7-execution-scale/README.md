## Convention

- **Demo** - короткий self-contained приклад до однієї концепції. Запускається `make`.
- **`make verify` / `make test`** - DoD-проба. Червоно на чистому checkout (стартовий
  стан: реалізація - це `NotImplementedError`-стаби) у демо з кодом; зелено після
  успішного прогону. Виняток - 7.5, де `make verify` зелений (snippets-стор - це
  ціль, яку полить `/loop`-рецепт).
- **`make demo`** кличе `claude -p` або друкує кроки слеш-команди - недетерміноване,
  витрачає токени, тому в CI не ганяється.
- **snippets** - спільний running-приклад нових демо (7.1 - його дім). Той самий
  домен у 7.3 (умова завершення), 7.4 (незалежні історії для паралелі), щоб патерн
  переносився на власний проєкт без прив'язки до beer-lms.
- **beer-lms track** у кожному README - авторський референс на реальний приватний M6
  capstone (`course-lesson-mvp`), наводиться в ізольованому git worktree і **не**
  запускається автоматично.
