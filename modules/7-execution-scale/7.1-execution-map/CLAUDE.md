# CLAUDE.md · Snippets seed + execution map (Lecture 7.1)

Мінімальний контекст для seed-проєкту Module 7. Домен `snippets` - наскрізний
приклад модуля: один WORKING-модуль (`models`) і п'ять STUB-модулів, кожен
закріплений за своїм патерном виконання. Урок 7.1 - про мапу «яка задача → який
патерн», а не про конкретну фічу.

## Стек

- Python 3.12, `pytest`. Без бізнес-залежностей (тільки стандартна бібліотека).
- Код: `src/snippets/`. Тести: `tests/test_*.py`.

## Конвенції

- **Модулі** - у `src/snippets/<name>.py`. Публічні функції/класи експортуються напряму.
- **STUB → реалізація** - `models.py` робочий; решта кидає `NotImplementedError`.
  Кожен стаб має правильну сигнатуру і docstring із контрактом.
- **Atomic commit per story** - кожен закритий task у `tasks/tracker.md` = окремий
  commit з префіксом `feat:` (нова фіча) або `fix:` (виправлення).

## Не робити

- Не змінювати `tests/` - якщо тест падає, фіксити код, не тест.
- Не змінювати story-файли в `tasks/` - це контракти.
- Не чіпати `models.py` - він уже робочий і є контрактом для решти модулів.
- Не комітити `.venv/`, `__pycache__/`, `.pytest_cache/`.
