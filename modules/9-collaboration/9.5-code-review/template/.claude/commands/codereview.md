# /codereview — багатопрохідне рев'ю (без дефіса)

Один виклик, що проганяє три спеціалізовані проходи поспіль і зводить
результат в один звіт за пріоритетом. Не плутати з вбудованим `/code-review`
(із дефісом) — той робить лише прохід коректності.

## Кроки

1. **Коректність** — виконати `/code-review` (логічні баги, P1).
2. **Спрощення** — виконати `/simplify` (дублювання, читабельність, P2).
3. **Безпека** — виконати `/security-review` (інʼєкції, секрети, P0).
4. **Опційно** — підняти `code-reviewer-subagent` у чистому контексті для
   неупередженого вердикту ACCEPT/WARN/PARTIAL/REJECT проти AC PR.
5. **Звести** знахідки в один список, відсортований P0 → P1 → P2, кожна з
   `file:line` і фіксом.

## Аргументи

- `--comment` — запостити зведені знахідки інлайн-коментарями в PR.

## Очікуваний підсумок на цьому фікстурі

- **P0** — command injection у `notify_desktop` (`reminders.py`).
- **P1** — off-by-one межа у `due_within` (`reminders.py`).
- **P2** — дубльований формат-хелпер `format_short` (`model.py`).

Чисто на мердж можна йти лише після фіксу P0 і P1.
