# CLAUDE.md

Етикет репозиторію. Claude читає цей файл на старті сесії й тримається цих правил.

## Git
- Коміти у форматі Conventional Commits: `тип(область): опис`
  (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`).
- Назви гілок: `feat/<коротка-назва>` або `fix/<коротка-назва>`.
- У `main` напряму не пушимо. Робота йде в named-гілці, у `main` код потрапляє
  через Pull request.
- До своїх комітів додавай трейлер `Co-Authored-By: Claude <noreply@anthropic.com>`.
- `.env` не комітимо ніколи. У репо лишається тільки `.env.example` з плейсхолдерами.

## Pull requests
- Платформа: GitHub. PR відкриваємо через `gh pr create`.
- Заголовок PR у форматі коміта: `тип(область): опис`.
- Тіло PR: розділи «Що змінилось» і «Навіщо»; рядок `Closes #<issue>`.
- Новий PR відкриваємо як `--draft`, поки робота не завершена.
