# CLAUDE.md

Правила проєкту для Claude — і в локальній сесії, і в GitHub Action
(`@claude`, авто-рев'ю `/code-review`). Спільні з іншими рушіями пріоритети
рев'ю живуть у `AGENTS.md`; тут — загальна етика репо.

## Git
- Коміти у форматі Conventional Commits: `type(scope): description`.
- Гілки: `feat/<short-name>` або `fix/<short-name>`.
- Трейлер `Co-Authored-By: Claude <noreply@anthropic.com>` у комітах, які ти робиш.
- Ніколи не комітити секрети. У репо — лише `.env.example` з плейсхолдерами.

## Review guidelines
- Пріоритети P0/P1/P2 — як у `AGENTS.md` (P0 — безпека/корупція даних; P1 —
  логічні баги; P2 — дублювання/читабельність).
- Кожна знахідка — з `file:line` і конкретним фіксом.
- Рев'ю агента доповнює, а не заміняє тести, секрет-скан і SAST у CI.

## Безпека Action
- Workflow тригериться лише на наявність `@claude` у тексті (mention-режим)
  або на подію PR (авто-рев'ю). Токен — у GitHub Secrets, не в коді.
- Дій від імені користувача з write-доступом; зовнішні контриб'ютори не
  запускають дій напряму.
