# AGENTS.md

Спільні правила для агентів-рев'юерів цього репо. Файл читають **обидва** —
Codex (OpenAI) і Copilot (GitHub) — а заодно й Claude. Тримай правила
стек-агностичними й короткими: що довший файл, то слабший сигнал.

## Project context

Бекенд-сервіс із lookup користувачів і видачею токенів. Дані — у SQL.
Усі зовнішні входи (email, query-параметри, тіла запитів) вважаються
недовіреними, доки не доведено протилежне.

## Review guidelines

Пріоритети знахідок:

- **P0 — блокує мердж.** Безпека й корупція даних: SQL/command/path
  injection, хардкоднуті секрети, неперевірений недовірений ввід, що тече в
  запит/шелл/шлях; втрата даних.
- **P1 — лагодимо перед мерджем.** Логічні баги, хибні межі, неопрацьовані
  крайні випадки, регресії, відсутні тести на нову поведінку.
- **P2 — на розсуд автора.** Дублювання, читабельність, дрібні ризики стилю.

Правила проходу:

- Кожна знахідка — з посиланням `file:line`, класом проблеми і конкретним фіксом.
- Параметризуй SQL. Ніколи не конкатенуй ввід у запит.
- Секрети — у GitHub Secrets / env, ніколи в коді.
- Рев'ю агента **доповнює**, а не **заміняє** детерміновані перевірки (тести,
  секрет-скан, SAST) — вони мають жити в CI поряд.
