# TeamHub — База знань

## Загальна інформація

### Що таке TeamHub?
TeamHub — це платформа для управління командами розробки. Включає трекінг задач, код-рев'ю, CI/CD pipeline, моніторинг і командну аналітику. Створена для команд від 5 до 500 інженерів.

### Які є плани?
TeamHub пропонує три плани:
- **Free** — до 5 користувачів, базовий трекінг задач, 1 проєкт
- **Pro** — $12/користувач/місяць, необмежені проєкти, CI/CD інтеграція, командна аналітика
- **Enterprise** — кастомна ціна, SSO, audit log, dedicated support, SLA 99.9%

### Як почати?
Зареєструйтесь на teamhub.example.com, створіть організацію і запросіть команду через email. Free план активується автоматично. Перехід на Pro — в Налаштування → Billing.

## Фічі

### Трекінг задач
Канбан-дошки з колонками To Do, In Progress, Review, Done. Кожна задача має пріоритет (P0-P4), assignee, labels і due date. Підтримує sub-tasks і залежності між задачами.

### Код-рев'ю
Інтеграція з GitHub і GitLab. Pull request автоматично створює задачу в TeamHub. Підтримка code owners, автоматичний вибір reviewer на основі git blame, inline коментарі.

### CI/CD Pipeline
Вбудований CI/CD з YAML конфігурацією. Підтримує Docker, Kubernetes, AWS ECS. Pipeline запускається при push в main або при створенні PR. Артефакти зберігаються 30 днів.

### Командна аналітика
Дашборд з метриками: cycle time, lead time, throughput, deployment frequency. Порівняння по командах і спринтах. Експорт в CSV або підключення через API.

### Інциденти
Модуль On-Call: автоматичні алерти з моніторингу, ескалація по рівнях (L1 → L2 → L3), post-mortem шаблони, timeline інциденту. Інтеграція з PagerDuty і Opsgenie.

## Інтеграції

### Які інтеграції підтримуються?
TeamHub інтегрується з:
- **Git**: GitHub, GitLab, Bitbucket
- **CI/CD**: Jenkins, CircleCI, GitHub Actions
- **Моніторинг**: Datadog, Grafana, New Relic
- **Комунікація**: Slack, Microsoft Teams, Discord
- **Аутентифікація**: SAML 2.0, OAuth 2.0, LDAP (Enterprise)

### Як підключити Slack?
Налаштування → Інтеграції → Slack → Install App. TeamHub бот відправляє нотифікації про нові задачі, PR, інциденти і деплої в обрані канали.

### Як підключити GitHub?
Налаштування → Інтеграції → GitHub → Authorize. Потрібні права на repo та pull_request. Після підключення PR автоматично синхронізуються з задачами.

## API

### Чи є API?
Так, REST API доступний на всіх планах. Документація: api.teamhub.example.com/docs. Rate limit: 100 запитів/хвилину (Free), 1000 (Pro), 10000 (Enterprise).

### Як отримати API ключ?
Налаштування → API → Generate Key. Ключ починається з `th_`. Зберігайте в безпеці — він дає повний доступ до організації. Можна створити до 5 ключів з різними правами.

### Приклад API запиту
```
GET /api/v1/tasks?status=in_progress
Authorization: Bearer th_abc123...
```
Відповідь містить масив задач з полями: id, title, status, assignee, priority, created_at.

### Webhook
TeamHub відправляє webhook при подіях: task.created, task.updated, pr.merged, incident.opened. Налаштування → Webhooks → Add URL. Payload підписується HMAC-SHA256.

## Безпека

### Де зберігаються дані?
Дані зберігаються в AWS eu-central-1 (Франкфурт). Шифрування AES-256 at rest і TLS 1.3 in transit. Бекапи кожні 6 годин з retention 90 днів.

### SSO
Single Sign-On доступний на Enterprise плані. Підтримується SAML 2.0 (Okta, Azure AD, OneLogin) і OAuth 2.0. Налаштування: Адмін → Безпека → SSO → Configure.

### Двофакторна автентифікація
2FA доступна на всіх планах. Підтримує TOTP (Google Authenticator, Authy) і WebAuthn (YubiKey). Адміністратор може зробити 2FA обовʼязковою для всієї організації.

### Audit Log
Enterprise план включає повний audit log: хто, коли, що змінив. Зберігається 1 рік. Доступний через UI (Адмін → Audit) і через API. Фільтри по користувачу, дії, дату.

### SOC 2 та GDPR
TeamHub має сертифікат SOC 2 Type II. Відповідає GDPR: DPA доступний для Enterprise клієнтів, право на видалення даних, експорт даних в JSON.

## Troubleshooting

### Задачі не синхронізуються з GitHub
Перевірте що GitHub App має права на repo. Налаштування → Інтеграції → GitHub → Permissions. Якщо права є — натисніть Resync. Синхронізація може зайняти до 5 хвилин.

### CI/CD pipeline падає
Перевірте YAML синтаксис у файлі .teamhub/pipeline.yml. Поширена помилка: відступи в YAML (використовуйте пробіли, не таби). Логи доступні в Tasks → Pipeline → Logs.

### Повільний дашборд аналітики
Аналітика рахується в реальному часі. Для організацій з >1000 задач рекомендуємо фільтрувати по спринту або команді. Кеш оновлюється кожні 15 хвилин.

### Не приходять Slack нотифікації
1. Перевірте що бот додано в канал
2. Перевірте фільтри нотифікацій (Налаштування → Notifications → Slack)
3. Перевірте що Slack App не відключено (Slack → Apps → TeamHub → Settings)

### Як видалити організацію?
Адмін → Налаштування → Danger Zone → Delete Organization. Потрібно ввести назву організації для підтвердження. Дані видаляються протягом 30 днів (GDPR grace period).

## Pricing деталі

### Як працює billing?
Оплата помісячно або щорічно (знижка 20%). Рахунок виставляється на початку періоду. При додаванні користувачів — пропорційний перерахунок (proration).

### Чи є безкоштовний trial?
Pro план має 14-днів безкоштовний trial без кредитної картки. Enterprise — демо через sales team (sales@teamhub.example.com).

### Чи можна повернути гроші?
Повернення протягом 7 днів після оплати без питань. Після 7 днів — пропорційне повернення за невикористаний час.

## Ліміти

### Які ліміти по файлах?
Максимальний розмір файлу-вкладення: 50 МБ. Загальний обсяг: 5 ГБ (Free), 100 ГБ (Pro), необмежено (Enterprise). Підтримувані формати: будь-які.

### Скільки проєктів можна створити?
Free: 1 проєкт. Pro: необмежено. Enterprise: необмежено + project templates і cross-project залежності.

### Скільки користувачів в команді?
Free: до 5. Pro: необмежено. Enterprise: необмежено + гостьовий доступ (read-only) для зовнішніх стейкхолдерів.
