# LEGACY EXAMPLE

> **This example predates the v4.0.0 full-cycle upgrade and is NOT updated to the new cycle.**

It was created when the toolkit ended at `break-tasks`. As a result it uses the older artifact set and naming:

- `SPEC.md` instead of `PRD.md`
- `delivery/<slug>/` layout instead of `docs/features/<slug>/`
- No `tasks.json` (machine-readable DAG)
- No staged migrations under `migrations/`
- No `_review/` directory

The example is kept for historical reference only. For a current end-to-end example see [`examples/course-lesson-mvp/`](../course-lesson-mvp/).
